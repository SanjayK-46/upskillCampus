# IoT Smart Environment Monitoring System

## Project Overview

This project is an IoT-based Smart Environment Monitoring System developed using ESP32. It monitors temperature, humidity, and gas concentration in real time using sensors and uploads the data to the Blynk IoT Cloud platform.

---

## Features

- Real-time Temperature Monitoring
- Real-time Humidity Monitoring
- Gas Leakage Detection
- LCD Display
- LED Alert
- Buzzer Alert
- Wi-Fi Connectivity
- Blynk Cloud Monitoring

---

## Hardware Components

- ESP32 DevKit V1
- DHT11 Sensor
- MQ-2 Gas Sensor
- 16×2 I2C LCD
- LED
- Active Buzzer
- Breadboard
- Jumper Wires
